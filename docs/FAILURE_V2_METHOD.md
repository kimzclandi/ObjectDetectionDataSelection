# failure-v2 数据闭环方法

## 实验流程

从固定检测器的开发集漏检构造选样假设。低阈值预测用于识别可恢复漏检，全局特征建立原型；候选池排序只读取部署时可见字段，不读取池标签。选定样本后才获取参考标注用于训练。

定向新增、随机新增与仅继续训练三组共享初始权重、每组 112 个优化步及三个随机种子；新增组各选 12 张图。仅更新 ROI 预测头，骨干保持固定。九次训练全部完成后，在排除旧图像前缀组的 120 张新评测图上统一计算指标。

## 数据与接口

图像为 RGB 浮点张量 `[3,H,W]`，目标框为 `[N,4]`，类别为 `[N]`，全局特征为 `[256]`。`failure_loop.py` 中的 `diagnose/rank_pool` 负责诊断与排序，`schedule/train_run` 负责等预算训练，`metrics/analyze` 负责评测；`evaluation.py` 提供匹配及 COCO 指标。

## 解释边界

定向相对随机的平均 AP 差为 -0.634 点，区间跨零，未证明定向策略有效。按来源组 bootstrap 保留组内相关性；文件名前缀并不等同于经确认的驾驶会话。选样症状不能直接解释训练差异的原因。

原始预测、分母、非目标切片和恢复记录见 [实验报告](FAILURE_V2_REPORT.md)。后续机制分析见 [开发集诊断](DIAGNOSIS_V3_REPORT.md)。代码与文档使用 AI 辅助开发。
