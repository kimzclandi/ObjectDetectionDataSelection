# 数据闭环研发岗位 · 能力与证据地图

这份映射只描述仓库已实现或待补齐的能力，不声称拥有企业规模经历。

| JD 能力 | 已运行证据 | 当前边界 |
|---|---|---|
| 数据回收、挖掘、生产流水线 | 固定源接入、并发下载、质量检查、样本目录、采样计划与模型预标注复核队列 | 公开数据离线接入，不是真实车端回传 |
| 高价值样本筛选 | 三策略、三种子、共同初始权重、同图像预算、逐样本追踪 | 仅 240 张图；多样性无显著收益证据 |
| 模型效果量化验证 | 真实检测头微调、固定集 AP/切片、匹配优化步数的三组补充消融 | 不是全模型训练；补充对照是后验设计 |
| 大模型数据应用 | 固定权重 SmolVLM 真实图像推理、原始文本、严格解析、失败分母、复核队列 | 只有昼夜标签，未人工裁决、未测降本 |
| 数据存储与检索 | 图像与元数据分离、Parquet + DuckDB、内容哈希、数据版本 | 无对象存储集群、PB 级检索或容量验证 |
| Ray 技术栈 | 真实 1/2/4 worker 扫描、逐 ID 与串行输出相等、实测调度开销 | 单机轻工作负载；不是多机训练 |
| 故障排查与系统设计 | 进程中断注入、running 恢复、事务提交、幂等缓存、失败不丢样本 | 单 runner SQLite，无分布式租约 |
| Python 与计算机基础 | 带类型接口、模块划分、边界测试、CI、冻结依赖、证据清单 | Java/Go/C++、Spark/Flink 源码需要另外准备 |

## 五分钟演示顺序

1. 打开实验对照，解释为什么微小优势不足以宣称策略有效。
2. 打开一个失败图像，说明绿色 GT、橙色预测、漏检与误检怎样计算。
3. 打开采样计划，追踪入选 ID，并解释为什么采样器拒绝真实标签字段。
4. 展示 seed-only 补充消融，区分新增数据与额外训练的作用。
5. 打开 VLM 质检，展示格式失败与语义错误如何分开处理。
6. 展示中断恢复凭证和 Ray 实测，解释哪些结论不能扩展到 PB 级。
