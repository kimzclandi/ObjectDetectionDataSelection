# 历史 pilot 方法说明

本页对应早期 240 张道路图像实验。当前主线结果见 [研究索引](RESEARCH_INDEX.md)，不同轮次的结果不能合并比较。

## 输入、处理与输出

输入为公开道路图像及参考标注。先使用 44 张图像微调检测头，再以相同新增 12 图预算比较随机、不确定性和多样性采样，每种策略运行三个随机种子。输出包括入选样本、模型身份、逐图预测和固定评测集指标。

训练仅更新 466,375 个 ROI 预测头参数，不是全模型微调。匹配训练步数的补充对照用于区分新增数据与额外优化步数，属于后验设计。

## 结果与限制

多样性相对随机的平均差异只有 0.045 个 AP 百分点，不支持显著收益结论。单机 Ray 扫描核对了逐 ID 输出一致性，但轻量任务的调度成本使其慢于串行；这不构成多机吞吐结论。

数据版本、幂等缓存和任务恢复服务于结果追溯。恢复验证与统计有效性是不同检查：任务成功完成不代表采样策略有效。
