# 失败驱动数据选择 v2：实际实验报告

**本轮不支持定向策略优于随机。** 三seed定向−随机平均 **-0.634 AP百分点**；预设200次组级配对bootstrap区间 **[-1.631, +0.323]**。不继续改规则追正结果。

本实验新增的是可追溯失败假设、事前匹配训练对照与120张新评测图，不是重复旧三策略实验。冻结提交 `37eba66` 在训练前包含源代码、名单、权重、协议和manifest。方法与复现见 [协议](FAILURE_V2_PROTOCOL.md)。

## 假设与实际干预

开发集621目标：阈值0.5时TP113/FP79，0.05时TP168/FP911。27张开发图包含可恢复漏检，其256维特征形成失败原型。这个干预证明部分匹配框已存在，未证明内部根因，FP激增也是明确反证。

池端评分只读取像素预测和特征，使用原型相似度与低置信度质量；不读pool标签。定向从前36候选随机抽12图，random从101图抽12图。seed-only重复旧图，所有组112步、共同warmup、相同超参数。全部九模型完成后才评测，只有最终checkpoint，无早停/最佳seed选择。

## 反证与决策

有机制解释的选择没有稳定胜出；全局特征相似可能不等于梯度价值，低分框中包含大量背景误检，冻结骨干也可能限制改进。没有组件消融，不能判定失败是原型、低分质量还是训练能力单独造成，更不能倒推“主动学习无效”。

目前保留随机作为参考政策，不批准这条定向规则替代它。下一次若继续，应先在新开发实验检查原型判别力和噪声率，再另行预注册新评测；本轮不改公式、不重选子集。

预算只匹配12图，新增标注框数实际为 `{"targeted-s101": 209, "random-s101": 149, "targeted-s211": 275, "random-s211": 122, "targeted-s307": 210, "random-s307": 202}`。未匹配人工时间、标注工作量或标签质量，公开标注是模拟获取，人工审核状态仍待完成。

## 工程、计算和证据

- 九组正式训练共 1008优化步，累计记录训练时间 122.8秒；不含模型初始化和数据准备。
- 一个额外不中断重放仅用于恢复验证，不用于选模型或汇总策略收益。与第14步中断恢复的330个最终张量及112步loss完全相同，见 `resume_verification.json`。
- 10模型×120图=1200条原始推理记录，累计单图计算时间 125.4秒；CPU、无付费API/云资源。
- 新数据与旧240图的全部前缀组隔离；像素/近重复排除和原始索引revision有记录。前缀不是已验证路线/驾驶会话，仍是同源公开数据小实验。
- 主模型、数据、标签、源代码、依赖、配置和名单全部摘要校验；逐图原子记录、错误记录和训练恢复不静默覆盖历史。
- `.venv/bin/python scripts/verify_failure_v2.py` 从原始预测和下载参考标签重算AP、召回、精确率；`analyze`还重算预设bootstrap。CI进行合同/已存证据检查，不声称重新训练。
